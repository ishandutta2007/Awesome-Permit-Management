# Awesome-Permit-Management

## Top Permit Management Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on Building Permits, Licensing, Plan Review, Inspections, Code Enforcement & Municipal Workflow Automation*  

**Last updated: September 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Permit Management**. These systems help local governments, building departments, and agencies manage permit applications, plan reviews, inspections, licensing, and related civic workflows from intake through approval and compliance.



**Examples** include OpenGov Permitting, Accela, Tyler Technologies EnerGov, CityView, Clariti, SmartGov, Cloudpermit, PermitFlow, MyGov, and PermitVision (the category leaders).



**Open-source emphasis**: Full-featured, production-ready open-source permit management systems comparable to commercial municipal platforms are limited. Most available projects focus on standards (OpenPermit), specific federal or regional use cases, code enforcement, or supporting GIS/data tools. This section lists every significant active project and related building blocks found.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects



- **[OpenPermit Specification](https://github.com/openpermit/openpermit.github.io)**  

  Open standard and API specification for presenting permit information, requirements, applications, and process operations in a unified format. Aims to enable interoperable permitting applications across jurisdictions.



- **[permit-portal](https://github.com/acgsa/permit-portal)**  

  Open-source centralized federal permit portal focused on streamlining NEPA (National Environmental Policy Act) review, project intake, agency routing, and workflow-driven task management.



- **[CodeNForce](https://technologyrediscovery.github.io/codenforce/)**  

  Open-source municipal code enforcement and occupancy permitting web application. Supports code enforcement workflows, notices, and related local government processes.



- **[e-permit related projects](https://github.com/e-permit)**  

  Collection of open-source components around electronic permit systems, including verification tools and supporting applications.



- **[XPlanung-light and planning tools](https://github.com/mrmap-community/xplanung_light)**  

  Open-source tools (primarily European/German context) for managing and publishing spatial planning and building-related plan data in simplified form.



- **[Civic GIS & data platforms (GeoMoose and similar)](https://www.geomoose.org/)**  

  Open-source web mapping frameworks used by municipalities to expose permitting, licensing, infrastructure, and other geospatial data to staff and the public.



- **[Permit data & research tools](https://github.com/search?q=building+permit+OR+municipal+permitting)**  

  Community projects for scraping, structuring, analyzing, or visualizing building permit data (regional examples exist for specific jurisdictions).



### Additional Strong Open-Source Options



- **Workflow engines**: BPMN tools (e.g., SpiffWorkflow, Camunda community) that can power custom permit review and approval processes.

- **Form & document platforms**: Open-source form builders and document management systems adaptable for permit applications and plan submittals.

- **GIS stacks**: QGIS, PostGIS, GeoServer, and related tools commonly used alongside or behind municipal permitting systems.

- **Low-code / civic tech frameworks**: Platforms that governments can configure for intake, routing, and case management.

- **Standards work**: BLDS, PIC, and other permitting data standards that improve interoperability.

- Prototypes and academic projects exploring AI-assisted plan review or automated permit intake (generally early-stage).



**Frameworks for building custom systems**:  

There is currently no widely adopted, full-featured open-source equivalent to commercial platforms such as Accela, OpenGov, or EnerGov.  

Organizations typically rely on commercial systems for production permitting because of complex multi-department workflows, legal/audit requirements, payment integration, and long-term support needs.  

Open-source components (OpenPermit standards, workflow engines, GIS, form tools, and projects like CodeNForce or permit-portal) can support custom or hybrid solutions, prototypes, data interoperability, and specific regional use cases.  

Many agencies combine commercial permitting software with open GIS and data-publishing tools for public transparency.

## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- Permit management systems handle regulated processes, legal records, fees, and often sensitive applicant data. Any system used in production must meet applicable public-records, accessibility, security, audit, and procurement requirements.

- Open-source projects in this domain are valuable for standards, research, transparency, and custom development but are rarely drop-in replacements for enterprise municipal permitting platforms without significant additional work, testing, and operational support.
